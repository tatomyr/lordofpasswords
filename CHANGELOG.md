# Changelog

## [1.0.0-rc.1] - 2026-10-18

### Added

- A dark colour scheme that follows the system preference.
  The form controls and the browser dialogs follow it too.

### Fixed

- The clipboard fallback prompt now appears when the clipboard write fails.
  Before, the app reported "Copied to clipboard" and the prompt never appeared.

## [1.0.0-rc.0] - 2024-03-27

### Changed

- The service name is case insensitive by default.
- The page shows the date of the latest revision.
